# Bienvenue sur ChuWiki !

## Qu'est-ce que c'est  ?

ChuWiki est tout d'abord un wiki. Un wiki est un site web dont les pages sont éditables par le visiteur. La page que vous lisez actuellement peut d'ailleurs être éditée. Un système d'historique permet toutefois de suivre les modifications effectuées sur une page et de restaurer une ancienne version de la page si besoin.

## ChuWiki est simple !

Plus besoin de s'ennuyer à paramétrer sa base de données, ChuWiki n'utilise que des fichiers ce qui signifie un wiki plus rapide.

Plus besoin de s'ennuyer à modifier les sources de votre wiki pour retrouver la charte graphique de votre site, ChuWki utilise des thèmes HTML que vous pouvez modifier aisément, et si vous ne connaissez pas l'HTML, vous pourrez toujours modifier le design en changeant la feuille de style CSS du thème par défaut.

Plus besoin de s'ennuyer avec les moteurs de recherche, les adresses lisibles utilisées par ChuWiki assurent un bon référencement des pages dans tous les navigateurs.

Plus besoin de s'ennuyer avec des syntaxes wiki complexes, ChuWiki utilise une syntaxe simple et intuitive. Si vous désirez essayer la syntaxe, vous pouvez toujours vous amuser dans notre Bac à sable.

# Installer ChuWiki

1. Téléchargez l'archive contenant ChuWiki.
2. Avec un outil de décompression (WinZip, WinRar, 7-Zip), décompressez l'archive de ChuWiki que vous venez de télécharger.
3. Avec un logiciel de FTP (FileZilla, SmartFTP), uploadez les fichiers de ChuWiki sur votre site web.
4. Si votre hébergeur utilise un autre nom que .htaccess pour les fichiers de configuration serveur, vous devrez le renommer. Il y a un de ces fichiers à la racine du site. Si vous ne comprenez pas, laissez ces fichiers ainsi.
5. Connectez vous sur votre site web, et voilà ! Votre wiki est en place et vous pouvez commencer à l'utiliser. Si cela ne fonctionne pas, reportez-vous à la page des Problèmes d'installation.
6. Vous pouvez ensuite adapter ChuWiki à vos besoins en modifiant le fichier de configuration Configuration.ini et/ou en modifiant les templates HTML et/ou CSS.
